Source code

LAME, mpg123, libsndfile, the Musepack encoder and TTA are covered by the GNU LGPL. Each is a separate framework inside OldTunes.app, in Contents/Frameworks. The source code they were built from, with its build settings and patches, is at github.com/sbooth/AudioXCFrameworks, in the lame, mpg123, sndfile, mpc and tta-cpp folders. Each project also publishes its own source: lame.sourceforge.io, mpg123.de, github.com/libsndfile/libsndfile, musepack.net and sourceforge.net/projects/tta.

TagLib's source code is available under the Mozilla Public License 1.1 at github.com/taglib/taglib. The copy built into OldTunes is version 2.3.2, from github.com/sbooth/CXXTagLib.
